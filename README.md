**🚆 Railway Track Crack Detection using Deep Learning**
**📌 Project Overview**

This project focuses on automated detection of cracks in railway tracks using Deep Learning and Computer Vision techniques.
The system identifies defective track regions, detects cracks, and maps their geographical location to improve railway safety and maintenance efficiency.

**🎯 Key Features**

Classification of railway tracks as defective / non-defective

Crack detection using YOLOv5

Crack width estimation with bounding boxes

Geospatial localization using latitude & longitude

User-friendly visualization of results

**🧠 Technologies Used**
Python

YOLOv5

EfficientNet

Deep Learning & Computer Vision

Geospatial Mapping

Git & GitHub

📂 **Dataset**

Railway Track Fault Detection Dataset (Kaggle)

Images with GPS coordinates

Split into training, validation, and testing sets
